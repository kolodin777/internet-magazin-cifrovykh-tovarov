# Диаграммы интернет магазина цифровых товаров

Исходники написаны на PlantUML. Для генерации всех PNG:

```powershell
java -jar plantuml.jar -tpng diagrams\*.puml
```

Основные диаграммы:

- `use-case-diagram.puml`
- `ER-diagram-database.puml`
- `domain-model.puml`
- `component-diagram.puml`
- `contextual-business-process-model.puml`
- `JWT-authentication-sequence.puml`
- `sequence-saving-result-and-notification.puml`
- `DDL-scripts.puml`

Дополнительно для пояснительной записки:

- `purchase-activity-diagram.puml`
- `deployment-diagram.puml`
- `download-access-state-diagram.puml`
